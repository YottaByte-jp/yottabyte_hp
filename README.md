# YottaByte Homepage

Static prototype for the YottaByte freelance engineering homepage.

## Run locally

```bash
python3 -m http.server 5173
```

Then open:

```text
http://localhost:5173
```

## Design direction

- Monochrome, minimal, and quiet tone
- Large YottaByte logo in the header
- Ambient canvas animation in the background
- Sections for services, about, profile, and contact
