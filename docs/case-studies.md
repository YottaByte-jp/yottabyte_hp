# 対応事例の編集方針

2026年10月30日に、提供された非公開スキルシートの「職務経歴・案件詳細」6件を読み取り、既存の支援内容の例4件を差し替えました。元資料そのもの、公開先で顧客を特定できる名称・URL・契約情報は、このリポジトリに保存しません。

サイトでは代表が携わった開発経験として紹介します。個人の経験を法人が受注した契約と断定せず、フリーランス・インターンなどの契約形態や所属先、案件期間は記載しません。担当した範囲と案件全体の範囲を混同せず、資料にない工数削減率・売上・利用者数などの成果数値は加えません。技術製品の名称は、使用技術の説明として必要なものを記載します。

## 画像

サムネイル6点は内蔵image_genで作成し、`public/generated/cases/`のWebPを一覧と詳細ページの先頭で使用します。紙・陶器・ガラス・金属の立体的な質感を持つビジュアルで、白・グレー・コバルトブルーの配色と柔らかい光を揃えています。決済、業務データ連携、LLM、動画分析、データ可視化、API保守を別々のモチーフで表現しています。最初の決済画像を他5枚のスタイル参照に使用しました。

使用プロンプトは`docs/image-prompts/cases/`、生成記録と元画像の寸法は`docs/image-generation.json`に記録しています。元PNG・Web用WebP・プロンプトはダウンロード内の`YottaByte_HP画像_20261030/対応事例/画像生成版`にも保存しています。拡大処理は行っていません。

詳細ページの技術連携の概念図は、`scripts/generate-case-illustrations.mjs`で作成したSVGを維持しています。このスクリプトが出力する旧SVGサムネイルは候補として残し、現行の事例サムネイルには使いません。生成画像・概念図とも顧客の画面・ロゴ・実データは含めず、実際の製品や完全な顧客環境の構成を再現したものではありません。事例の本文・担当範囲・使用技術とページ構造は、サムネイルの差し替えでは変更していません。

旧4件のデータと専用サムネイルの参照を削除し、旧URLは生成対象・サイトマップから外します。旧図のうち事業内容ページにも使われていた2点は、`automation-workflow.svg`と`automation-development.svg`へ用途に合う名前で移し、事業内容ページの見え方は維持しています。

## ページの範囲

トップ、企業情報、事業内容、お問い合わせ、ヘッダーの基本構成は維持します。対応事例の一覧・カテゴリ・詳細の内容と、それらを参照する事例枠を更新します。事例一覧には匿名化と開発経験に基づく旨を一文で示し、詳細は案件ごとの本文に差し替えています。
